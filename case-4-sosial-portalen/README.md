# Case 8: Sosial-portalen

## Kort beskrivelse
Lag en intern sosial portal for ansatte med aktiviteter, grupper og en enkel feed for deling av innlegg.

## Hvorfor denne casen
- Sosial og visuell case som er lett a demonstrere
- Gir trening i UI-komponenter, filtrering og interaksjon
- Egner seg godt for kreativ AI-assistert frontendutvikling

## Forslag til MVP
- Feed med innlegg (tekst, forfatter, tidspunkt)
- Aktivitetskalender med pamelding (f.eks. lop, sjakk, lunsj)
- Grupper med kategorier (idrett, fag, hobby)
- Enkel reaksjon pa innlegg (liker)
- Filtrering pa gruppe eller aktivitetstype

## Brukerhistorier
- Som ansatt vil jeg se hva som skjer i organisasjonen.
- Som ansatt vil jeg melde meg pa en aktivitet.
- Som ansatt vil jeg finne grupper som matcher interesser.
- Som arrangor vil jeg se hvem som er pameldt.

## AI-prompter dere kan starte med
Be ai lage issues for: 
- "Lag demodata som dere tror kan trenges"
- "Bygg en feed-komponent med kort og tidsstempler."
- "Lag filterlogikk for aktiviteter og grupper."
- "Implementer pamelding med enkel validering av deltakergrense."
- "Skriv tester for filtrering, pamelding og reaksjoner."

## Ferdig når
- Bruker kan lese feed, finne aktiviteter og melde seg på
- Filtrering og reaksjoner fungerer stabilt
- Kjerneflyter er testet
