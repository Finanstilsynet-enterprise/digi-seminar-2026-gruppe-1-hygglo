# KI-drevet utvikling med GitHub Copilot og Codespaces

> **Hurtigguide til workshopen**

---

## 🏠 Repository (repo)

**Tenk på det som et prosjektrom.**

Her ligger alt som hører til prosjektet:

- Dokumenter
- Kode
- Oppgaver (issues)
- Historikk

**Eksempel:**
«Repositoryet er prosjektmappen vi skal jobbe i under workshopen.»

---

## 📋 Issue

**Tenk på det som en oppgave eller arbeidsordre.**

Et issue beskriver noe som skal gjøres:

- En ny funksjon
- En feil som må rettes
- En forbedring

**Eksempel:**
«Lag en side som viser dagens dato.»

---

## 🤖 GitHub Copilot

**Din KI-assistent.**

Copilot kan hjelpe deg med å:

- Lage forslag til oppgaver (issues)
- Opprette issues i github
- Lese issues i github
- Skrive kode
- Forklare kode
- Finne feil
- Gi forslag til forbedringer

**Tenk på Copilot som en kollega du kan stille spørsmål til.**

---

## ☁️ Codespaces

**Et ferdig arbeidsmiljø i nettleseren.**

Du trenger ikke installere noe lokalt.

Codespaces gir deg:

- En ferdig datamaskin i skyen
- Tilgang til repositoryet
- Copilot integrert i arbeidsflaten

**Tenk på det som en PC i skyen der du kan jobbe med prosjektet.**

---

## 💬 Prompt

**Instruksjonen du gir til Copilot.**

Jo tydeligere du er, desto bedre svar får du.

**Mindre bra:**

> Lag noe som viser data.

**Bedre:**

> Lag en enkel nettside som viser dagens dato og klokkeslett.

---

## 🔄 Slik fungerer workshopen

```text
1. Opprett et issue
          ↓
2. Be Copilot løse oppgaven
          ↓
3. Test resultatet i Codespaces
          ↓
4. Be copilot `push` til `main`

koden oppdateres så de andre i teamet også kan bruke den.
```

---

## Husk

- ✅ Du trenger ikke kunne programmere for å delta
- ✅ Beskriv problemet eller ønsket resultat med egne ord
- ✅ Copilot hjelper deg gjennom arbeidet
- ✅ Målet er å lære hvordan mennesker og KI kan samarbeide

---

## Enkel huskeregel

| Begrep | Tenk på det som |
|---|---|
| Repository | Prosjektrom |
| Issue | Oppgave |
| GitHub Copilot | KI-kollega |
| Prompt | Instruksjon |
| Codespace | Kontor i skyen |
| Push | Send endringene dine til de andre |
